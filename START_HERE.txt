QUIET NEURONS
DataForge 2026, Pathway track ("Explain the Frontier")
Concept: Sparse Non-Negative Activations
Nilay Toshniwal, solo entry

THE CLAIM
  This model goes quiet on words it has just picked up from the text in front of
  it. It does not go quiet just because text is easy to guess. From the outside
  those two look identical, and they are not the same thing.

RUNNING THE ARTIFACT FROM THIS ZIP

  Double-clicking web/index.html will NOT work, and this is worth knowing before
  you conclude the page is broken. The page fetches its weights and runs the model
  inside a module Worker, and browsers block both of those on file:// URLs. Opened
  that way it renders the text and leaves every number as a dash.

  Serve the folder instead:

      cd web
      python -m http.server 8123

  then open  http://localhost:8123  in a browser. No dependencies are needed for
  this; it is plain static hosting.

  Or simply use the live URL at the top of this file. It serves these same files.


CHECKING THAT THE MODEL IS REAL

  web/parity.html  runs the browser's JavaScript forward pass against a PyTorch
  reference trace and prints the difference. It is the first thing a sceptical
  reader should open. Live copy:

      https://nilaymastaadmi.github.io/quiet-neurons/parity.html


NOT IN THIS ZIP

  experiments/checkpoints/*.pt  --  the three trained models, 37 MB together. They
  are in the GitHub repository linked above. experiments/measure.py re-derives every
  published number from them without retraining anything, in a couple of minutes of
  CPU. Training from scratch is also documented in the README, and takes about an
  hour for the model that runs on the page (2,309 steps at roughly 1.45 s per step).
